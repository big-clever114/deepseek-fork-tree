# 分叉树右键菜单设计（0.1.11）

日期：2026-11-06
范围：DeepSeek 对话分叉树浏览器扩展，右侧抽屉内的树卡片。

## 背景与目标

树卡片目前只有左键点击打开详情面板，常用操作（定位、切版本、复制）都要先进详情再点按钮。目标是在卡片上右键直接拿到这四个动作，减少一次跳转。

## 范围

做：

- 树卡片上的右键快捷菜单，四个菜单项：定位到这一版、切到这一版、复制消息内容、复制分支路径。
- 菜单的定位、翻转、关闭与置灰规则。
- 深色/浅色主题跟随现有 `#dst-host` 变量。

不做：

- 左侧 DeepSeek 气泡上的右键菜单。
- 画布空白处、详情面板上的右键菜单。
- `chrome.contextMenus` 系统级菜单与新增权限。
- 键盘方向键在菜单内导航（只支持 Esc 关闭）。

## 交互

1. 在 `.dst-card` 上触发 `contextmenu` 时阻止浏览器默认菜单，在光标处打开插件菜单。
2. 打开菜单的同时把该卡片设为选中态（`is-selected`），不打开详情面板。选中态直接改卡片 DOM 的 class（清掉其他卡片的 `is-selected`），不调用 `renderNow()`，避免“重渲染即关菜单”把自己关掉。
3. 菜单 `position: fixed`，`z-index` 高于详情面板；超出窗口右/下边缘时向左/上翻转，至少留 8px 边距。
4. 以下任一情况关闭菜单：Esc、在菜单外按下指针（`pointerdown`，菜单内点击不算）、滚轮、画布开始拖动、抽屉重新渲染、再次右键另一张卡片（替换内容）。
5. 菜单项点击后先关闭菜单，再执行动作。

## 菜单项与规则

| 菜单项 | 动作 | 可用条件 |
| --- | --- | --- |
| 定位到这一版 | 复用现有 `locate(node)` | 始终可用 |
| 切到这一版 | 复用现有 `reveal(node)` | 仅 `node.hidden === true` 且非 `node.virtual` |
| 复制消息内容 | 复制 `node.text` | 有非空正文 |
| 复制分支路径 | 复制从根到该节点的可读链 | 始终可用 |

- 不可用的菜单项渲染为置灰（`disabled`），点击无动作。
- 复制成功后在状态条提示：`已复制这条消息` / `已复制分支路径`；复制失败提示 `复制失败，请手动选中文本`。
- 复制实现优先 `navigator.clipboard.writeText`，不可用或被拒绝时回退到临时 `textarea` + `execCommand('copy')`。
- 分支路径格式：从根节点到目标节点，每段为 `角色：正文前 20 字`，角色取 `你` / `DeepSeek` / 原角色名；无正文段写 `（无正文）`；段间用 ` → ` 连接。
- 复制内容不做额外加工，保留原始换行。

## 实现落点

- `src/drawer.js`
  - 新增菜单容器与 `openCtxMenu(node, clientX, clientY)`、`closeCtxMenu()`、`copyText(text)`。
  - 在画布上以事件委托监听 `contextmenu`，命中 `.dst-card` 才处理。
  - `renderNow()` 与 `load()` 时关闭菜单。
  - 菜单项复用现有 `openDetail` 之外的回调：定位走 `onLocate`，切版本走 `onReveal`。
- `src/drawer.css`
  - 新增 `.dst-menu`、`.dst-menu-item`、`.dst-menu-item[disabled]` 样式，只使用 `#dst-host` 上的 CSS 变量。
- `src/content.js`：不改接口；复制逻辑在 drawer 内完成，因为节点数据已加载在 drawer。
- `manifest.json`：版本升到 `0.1.11`。
- `install-guide.html`：补一条 0.1.11 更新说明。

## 边界情况

- 详情面板是 `inset: 0` 的整层覆盖，打开时卡片被遮住，右键不会命中卡片；这是既有行为，不在本次改动范围。
- 右键不会触发画布拖动：`pointerdown` 已对非左键直接 return。
- 虚拟/断链节点：定位可用（由 `locate` 自己报告找不到），切版本与复制正文置灰。
- 缩放/平移后菜单以视口坐标定位，关闭即失效，不需要跟随画布。
- 菜单打开期间抽屉重新渲染（例如切版本成功）：菜单关闭，避免指向已失效的节点。
